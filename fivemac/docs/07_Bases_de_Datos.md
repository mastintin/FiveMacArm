# Bases de Datos

## TSQLite
Un wrapper sobre `libsqlite3` nativo de macOS (serverless). Cero instalación requerida por el usuario.
Proporciona métodos xBase estándar (`GoTop`, `Skip`, `EOF`, `Append`, `FieldPut`) para que los desarrolladores Harbour lo usen idénticamente igual a los DBF.

## TMySQL
Modernización del acceso a MySQL para soportar nativamente funciones de Harbour standard en las resultsets y ejecutar comandos directos SQL eficientemente.
