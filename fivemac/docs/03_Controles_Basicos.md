# Controles Básicos

Esta sección cubrirá los controles fundamentales en FiveMac utilizados en la mayoría de diálogos y ventanas.

- **Ventanas y Diálogos**: La base contenedora. (TWindow, TDialog)
- **Say / Textos estáticos**: Para mostrar información y etiquetas. (TSay)
- **Get / Entradas de texto**: Entradas alfanuméricas tradicionales. (TGet, TMultiGet)
- **Botones**: TButton, TBtnBmp.

*(Nota: Esta sección está en construcción. Los parámetros de cada control se agregarán próximamente).*
