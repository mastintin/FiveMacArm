# 📚 Centro de Documentación FiveMac

Bienvenido a la documentación oficial de FiveMac. El framework se divide actualmente en dos grandes ecosistemas: la arquitectura moderna **SW** y el framework **Nativo Clásico**.

---

## 🚀 1. Módulo SW (La Isla): El Futuro
**SW (Swift Island)** representa la Arquitectura 2.0 de FiveMac. Es un ecosistema reactivo basado en SwiftUI que elimina las barreras tradicionales del desarrollo xBase en macOS.

*   **[👉 ACCEDER AL PORTAL INTERACTIVO DE SW (La Isla)](https://mastintin.github.io/FiveMacArm/)**
*   **Conceptos Clave**:
    *   **Arquitectura Dual-Thread**: Interfaz fluida (Hilo 0) + Lógica Harbour (Hilo 1).
    *   **Reactividad**: La interfaz se sincroniza automáticamente mediante JSON.
    *   **Poder Moderno**: Acceso total a SwiftUI y las últimas APIs de Apple.
*   **Documentación Técnica**: [Ver Catálogo de Controles SW](https://mastintin.github.io/FiveMacArm/)
