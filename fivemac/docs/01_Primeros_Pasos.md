# Primeros Pasos con FiveMac

## Introducción
FiveMac es una potente librería GUI para **Harbour** que te permite crear aplicaciones nativas de macOS utilizando el framework Cocoa de Apple.

## Requisitos Previos
1. **Xcode Command Line Tools**: Necesario para compilar el código fuente.
2. **Harbour**: Compilador de Harbour (versión de 64 bits recomendada).Harbour 64bits se proporciona en este repositorio compilado en un M4 y macos 26.2 .

## Compilando la Librería
Para construir `libfive.a` y `libfivec.a`, ejecuta el comando `make` en la raíz del proyecto.

## Ejemplo Básico
Para compilar una aplicación de ejemplo, navega a la carpeta `samples` y utiliza el script de construcción:

```bash
./build.sh tutor01
```
